# Convert a CSS hex colour to Excel ARGB format

Convert a CSS hex colour to Excel ARGB format

## Usage

``` r
hex_to_argb(hex)
```

## Arguments

- hex:

  A hex colour string, with or without a leading `#` (e.g. `"#cc0000"`
  or `"cc0000"`).

## Value

A string in `"FFrrggbb"` format (uppercase).
