# Text colour (black or white) for contrast on a system background

Text colour (black or white) for contrast on a system background

## Usage

``` r
sys_text_color(system_id, color_map)
```

## Arguments

- system_id:

  A system ID string.

- color_map:

  Named character vector from
  [`default_color_map()`](http://guillaume-noblet.com/anaR/reference/default_color_map.md).

## Value

`"#ffffff"` for dark backgrounds, `"#000000"` for light ones.
